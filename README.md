# Карточки ПДД РК

Тренажёр для подготовки к теоретическому экзамену на водительские права в Казахстане.
177 карточек по 20 темам: правила, знаки с картинками, схемы перекрёстков — с интервальными
повторами (SM-2). Вся графика — инлайновый SVG, внешних ресурсов нет.

**Открыть:** https://REPLACE_ME/

На айфоне: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
После установки работает офлайн.

## Содержание

| | |
|---|---|
| Правила | обязанности водителя, светофор и регулировщик, разметка, маневрирование, скорость, обгон, остановка и стоянка, приоритет, ж/д переезды, автомагистраль, жилая зона, свет, буксировка, перевозка людей, самокаты |
| Знаки | 20 знаков с рисунками: приоритета, запрещающие, предписывающие, особых предписаний, предупреждающие |
| Схемы | 8 разборов очерёдности проезда перекрёстков |
| Экзамен | формат теста, пересдачи, документы, госпошлина |

Источники: текст ПДД РК (24pdd.kz) и Правила приёма экзаменов — приложение 3
к приказу МВД РК № 862 в редакции от 25.05.2026.

## Разработка

```sh
./build.py            # cards.json из исходников
./build.sh            # index.html (артефакт) и dist/index.html (PWA)
./serve.sh            # раздать dist/ в локальной сети
./deploy.sh           # выложить dist/ на GitHub Pages
```

Колода Anki: `anki/PDD-KZ-2026.apkg`, пересобирается `anki/make_apkg.py`.
